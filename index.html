How our robot works

Java code controls the motors that move our robot. The team can program how the motors run during a match.

A dedicated launcher propels balls toward the hoop at a suitable speed. The driver operates the launcher with a controller.

A camera uses Java code to detect ball colors, helping the team tell the different balls apart.
