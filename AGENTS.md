# Project instructions for AI agents

- Read [contribution.md](contribution.md) before making changes and follow its Karpathy coding guidelines.
- This is a **static-only website**: plain HTML, CSS, browser JavaScript, and static assets. Do not introduce a backend, server-side rendering, API routes, databases, or a required production Node.js process.
- Node.js packages and the local preview server are development/test tooling only. The website must remain deployable by serving the repository's static files directly.
- Run `node --test test/*.test.mjs` after changes; install the standalone check tools as documented in contribution.md. Verify interaction and layout changes in a browser.
- Keep the repository free of npm manifests, lockfiles, and Playwright configuration.
- Write commit messages as `type(scope): describe the change shortly`.
